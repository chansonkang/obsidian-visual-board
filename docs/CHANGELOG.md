以下按版本保留各次更新说明。后续版本可能替换早期交互；当前使用方式以 README 为准。

## 0.1.27 更新

首个正式 GitHub Release。修复源码测试依赖未随仓库提供的问题，将固定语言测试样例移入独立测试夹具，确保全新克隆或解压源码后可以构建并完成全部测试。新增产品介绍、同一视觉风格的 AI 品牌图、真实画板与 Markdown 编辑截图；完整保留此前各版本的原更新说明。继承 0.1.26 的更新检查、通知与主动下载入口，程序界面和已有本地布局保持一致。

0.1.26 的首次云端流程在发布安装包前被测试拦截，没有创建正式 Release；原标签和记录保留，修复使用新版本号发布。

## 0.1.26 更新

新增 GitHub 更新检查：画板设置和 Obsidian 插件设置都提供「检查更新」，命令面板也可运行「检查插件更新」。默认使用本项目公开仓库，联网时每天检查一次正式版本；发现新版后显示提示和设置角标，可查看说明、打开下载、稍后处理或忽略该版本。画板内的更新横幅在编辑结束或关闭当前窗口后显示，避免抢走输入焦点。可在设置关闭自动检查，关闭后仍能手动检查。

更新检查会访问 GitHub 的公开 Release API，并读取该 Release 的 manifest，核对插件身份、版本和最低 Obsidian 要求。请求不发送文章、文件名、画板排版或生图 API Key，也不需要用户提供 GitHub Token。打开发布页或下载会交由系统浏览器访问 GitHub；离线、访问失败或请求次数受限时保留本地功能，以后可重试。

「下载新版」打开浏览器中的正式安装包，不在插件内自动替换或执行代码。手动更新时退出 Obsidian，将新包的运行文件覆盖到原插件目录，保留 `data.json`、`draft-recovery.json`、`data.json.previous` 和布局备份；不要删除整个目录。重开后在画板设置确认实际运行版本。使用 0.1.25 或更早版本的朋友，需要先手动更新一次到 0.1.26 或后续版本，才有更新提示入口。

希望由工具管理后续下载安装，可在 Obsidian 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，在其 beta 插件入口添加 `chansonkang/obsidian-visual-board`，使用它检查、下载和重载插件。BRAT 需要仓库已经发布包含标准运行附件的 Release。Visual Board 自身负责提示和下载入口；尚未进入 Obsidian 官方社区目录，不能据此宣称已在官方目录上架。[作者发布流程](../PUBLISHING.md)。

## 0.1.25 更新

底部选中操作条改为「截断名称 + 常用图标 + 更多 + 取消选择」的紧凑胶囊。适配尺寸、文章联系、移动、样式与删除等次要操作保留在“更多”，所有原有功能继续可用，悬停有中英文说明。主工具栏提供统一 44×44 点击区域、分组与间距，和上方操作条保持独立位置；窄窗口将缩放控件上移，隐藏常驻多选说明，避免互相叠压。

修复重开时目录索引短暂不完整会移除已排好文章卡片的问题。索引未确认的缺项保留原组件身份、位置、尺寸、顺序及连线；真正删除仍通过原生事件和磁盘确认同步，跨目录移动继续正确更新。

标准本地存储新增校验、安全替换与 10 份滚动排版备份。重开优先读取原数据，损坏或丢失时使用最近有效备份；没有有效数据时停止写入并提示，不把空画板覆盖到原文件。组件布局、样式、顺序和关系改变会轮换备份；单纯切层、缩放和播放进度照常保存，但不挤占排版历史。最新恢复快照和 10 份排版备份保存在知识库配置区的独立目录（默认 `.obsidian/visual-board-layout-backups/obsidian-visual-board/`），整体替换插件文件夹后也能恢复。旧版插件目录内备份仍可读取；更新时保留 `data.json`、`layout-backup-*.json`、`data.json.previous`（如有）和 `draft-recovery.json`。

正常重开保存最新布局；从备份恢复时，可能回到最近一次成功保存之前的排版。插件不会自动找回更新前已被覆盖、且没有任何备份的旧坐标。安装包只包含程序与说明，不附带使用者数据。

## 0.1.24 更新

选中画板组件可用 Command+C / Ctrl+C 复制，用 Command+V / Ctrl+V 粘贴；也可使用选中操作栏的复制图标和底部工具栏的粘贴图标。文章、便签、图片、PDF、音频和嵌套 Board 均支持，多个组件保留相对位置、尺寸、颜色、叠放顺序及内部手工连线；粘贴不改变当前画布缩放。

文章和附件产生独立的真实本地副本，保存到目标画板对应目录；Board 连同实际文件夹、子层级和各层布局一起复制，同名自动添加副本后缀。Markdown 正文按原文复制，其中已有的文字链接保留原目标。组件剪贴板仅在当前知识库的插件会话内使用，有效期 30 分钟；重新启动、切换知识库或过期后请重新复制。编辑正文或选中文字时，快捷键继续用于文字复制粘贴。

电脑上的 `.md` / `.markdown` 可直接拖入画板：空白处落在当前目录和网格位置，文件夹图标上落在相应子目录，不自动进入下一层。外部文件采用复制导入，保留 UTF-8 正文、BOM 和换行；`.markdown` 保存为 `.md`。从 Obsidian 目录拖入现有文章，会移动真实文件到对应目录，使用原生链接更新并保留文章身份；同一目录内只调整位置。批量导入最多 32 个文件、每个 10 MiB、合计 40 MiB；文件有误时保留成功项并提示失败。

组件粘贴和新文件导入支持 Command+Z / Ctrl+Z 撤销、重做；撤销将新副本移入本地回收站，恢复时保留布局和后续正文修改。已有文章目录移动继续使用原有的移动撤销。复制大文件夹最多 2,000 个文件、250 MB；本轮不自动导入 Markdown 旁边未选中的外部图片。

标题与编号/圆点列表的切换改为正确替换段落结构，避免生成标题包列表或多层标题叠套；编号拥有独立留白，保留原文里合法的列表内标题结构。

## 0.1.23 更新

粘贴 Markdown 时，标题、加粗、斜体、列表、引用和表格直接以排版后的内容插入，不再把格式标记当作普通文字。空白段落输入 `# `、`## `、`### `、`- `、`1. `、`> ` 可转换为对应结构；行内完整加粗、斜体、删除线和代码写法可自动排版。也可继续使用图标工具栏，不必输入符号。代码块与显式转义保留字面内容。

已有文章的 Obsidian 高亮、任务列表和 Callout 在阅读、编辑时显示对应样式。正文修改后继续保存为 Markdown，未修改的原始块保持原文；Callout 类型与标题暂为只读，正文可编辑。右侧文章预览和搜索定位也改为排版内容，保留跳转到原文行的能力。

画板设置窗口显示实际已加载的运行版本 `Visual Board · 0.1.23`。更新时替换插件运行文件，保留原 `data.json` 和草稿恢复文件，重启 Obsidian 后确认此版本号。

## 0.1.22 更新

画板右上角新增地球图标，可直接选择「简体中文」或「English」；也可以在 Obsidian 插件设置中切换界面语言。语言偏好保存在当前知识库，重新打开或重启后沿用。设置保存失败时恢复原语言并显示原因。

顶部和文章编辑工具栏改为 SVG 图标按钮；鼠标悬停或键盘聚焦会显示当前语言的工具名称，禁用的操作也会说明原因。编辑工具栏保留正文、标题 1/2/3、加粗、斜体、圆点列表、编号列表、引用、表格和完成操作。支持 Alt+F10 进入编辑工具栏，方向键选择，Enter 执行，Escape 返回正文；撤销、重做仍归属当前文章。

设置、搜索、Board、便签/连线样式、表格面板及主要状态提示支持中英文。切换只修改界面文字，不翻译正文、文件名、路径或自定义 Board 名称；保留光标、选区、未保存草稿、各组件阅读位置、布局和缩放。新插入表格使用当前语言的默认列名，已有表格不受语言切换影响。

## 0.1.21 更新

在 Obsidian 文件列表删除文件后，画板会移除该文件的全部引用卡片和关联线；改名或移动文件后，卡片标题、路径和媒体名称会同步更新。旧布局的延迟保存不会把旧名称或已删除组件恢复回来。启动时等待知识库加载后核对已有失效组件，保留仍存在或暂时无法核实的文件引用；原有未保存草稿继续保留。

文章正文使用按文章独立的撤销历史。文字修改和插入正文的图片，在自动保存、结束编辑或同画板刷新后仍能 Command+Z / Ctrl+Z 撤销，Shift+Command+Z / Ctrl+Shift+Z 或 Ctrl+Y 重做；不会撤销另一篇文章。新增图片卡片和更换图片内容也支持画板撤销/重做。撤销插入会移除插入内容，保留本地图片附件，供重做或其他引用继续使用。撤销历史在本次插件会话内保留。

编辑工具栏新增「插入表格」，在工具栏旁选择 2–6 列、1–10 行正文（另含一行表头），也可选 2×2、3×3、4×4 预设。表格插入到当前段落后，保存为原生 Markdown；单元格可直接编辑，插入和文字修改均可撤销。代码块和已有表格内部暂不支持再插入表格，移到外部段落即可。

统一 Markdown 标题、原有加粗文字与编辑后加粗文字的颜色为 `#253140`，编辑前后保持一致。继续保留每张组件的阅读位置、已有布局和画布缩放。

## 0.1.20 更新

停留在同一画板时，每张文章、便签和 PDF 卡片独立保留阅读位置。编辑和自动保存另一篇文章、选中或调整组件、后台刷新后，旁边卡片不再回到顶部；代码块的横向滚动也会保留。同一文章的多个卡片可以停在各自不同的位置。

当前文章继续保留编辑光标、原有 Markdown 格式和撤销历史。切换画板仍使用原有层级导航和内容居中逻辑。

## 0.1.19 更新

新建文章成功后，画板会主动在 Obsidian 原生文件列表中展开并选中真实文件，并提示实际保存路径。刚新建的文件如果尚未完成侧栏索引，会短暂等待条目出现；不改变侧栏所在位置或画布缩放。

选中文章后可点击「在文件列表中显示」重新定位。文件已经保存、但文件列表关闭或定位失败时，会保留“已保存”的路径提示并解释定位问题，不会误报新建失败，也不会重复创建文章。创建完成前切换画板，会保留原保存位置并提示返回原画板。

## 0.1.18 更新

点击文章正文进入编辑后，卡片旁会显示编辑工具栏。把光标放到某段，或选中几段文字，点击「圆点列表」添加项目符号，点击「编号列表」添加顺序编号；同一按钮可取消对应列表。工具栏也提供正文、标题 1、标题 2、标题 3、加粗、斜体和引用等入口，点击「完成」可结束编辑。

工具栏悬浮显示，不挤压正文，不改变卡片的位置、大小和画布缩放。操作仍自动保存为本地 Markdown。正文内支持 Command+Z / Ctrl+Z 撤销，Shift+Command+Z / Ctrl+Shift+Z 或 Ctrl+Y 重做。含图片的段落暂不提供标题和列表结构转换，移到纯文字段落即可使用；图片位置与原始引用会保留。

## 0.1.17 更新

文章正文改为保留排版的就地编辑：点击后继续显示标题、粗体、列表、引用、表格和代码块，不再切换成整篇 Markdown 源码。可直接修改文字和已有表格单元格，编辑结果仍保存到本地 `.md` 文件。

编辑器保留未修改块的 Markdown 原文、文件属性、首标题、本地图片和文章链接。只改一段时，不会把整篇文章转换成新的 Markdown 排版。继续使用原来的自动保存、冲突提示、草稿恢复和卡片布局。

选中文字后可用 Command+B / Ctrl+B 加粗，Command+I / Ctrl+I 斜体。表格用 Tab / Shift+Tab 切换单元格；列表用 Tab / Shift+Tab 缩进。按住 Command / Ctrl 再点链接即可打开。网页 HTML 不直接注入编辑器；0.1.23 起粘贴 Markdown 文本可识别格式。已有表格可直接改内容，此版本不提供新建复杂表格的面板。

## 0.1.16 更新

已有便签可以单击标题或正文直接修改，修改自动保存到本地画板。空正文也能直接输入。选中便签后可从「编辑便签」入口打开完整编辑窗口，保存会修改原便签，取消保留原内容。

编辑保留原 ID、位置、尺寸、颜色、叠放顺序、所属画板和连线；调整颜色、八向拉伸及置顶/置底等操作继续可用。用便签顶部拖动把手移动组件，正文中的文字选择、换行和 Command+Z / Ctrl+Z 使用文本编辑行为。

切换层级或关闭画板前会保存便签的最新内容。后台刷新时保持正在编辑的内容和光标；恢复已保存便签时保留内容及已有布局。

## 0.1.15 更新

删除组件改为移到知识库本地回收站。文章、图片、PDF、音频会移动真实文件；关联本地文件夹的 Board 会连同文件夹内容移入回收站。同一文件的其他画板引用也会移除。便签和自由画板保存为可恢复的画板记录。

Command+Z / Ctrl+Z 可撤销删除，Shift+Command+Z / Ctrl+Shift+Z 可重做。恢复保留原文件路径、Board 层级、组件位置、尺寸、叠放顺序、颜色和相关连线；不覆盖其他组件后来调整的布局。回收记录保存在本地，重启后也能从画板的「回收站」入口恢复；原目录中出现同名文件时会停止恢复，不覆盖现有文件。正常移动、拉伸、对齐和排列继续自动保存到本地布局。

音乐卡片右侧的名称、格式、进度和控制按钮整体居中，拉伸后仍保持居中；前进按钮移除圆框，三个播放控制按钮大小和间距一致。

图片、音频和 PDF 导入后会真实保存在知识库附件目录，并在 Obsidian 原生文件列表展开、选中对应文件。选中已有附件卡片也会定位原生目录；保留文件列表当前侧栏位置。需启用「文件列表」核心插件。

## 0.1.14 更新

修复图片导入与旧快照之间的资源竞态。粘贴、本地选择和拖入的 PNG/JPEG/WebP/GIF 会真实解码后显示；原图按实际像素尺寸显示，外框四边统一保留 10 个画板单位的白边，卡片高度随图片变化，文件名不再占用额外底部行。旧固定 320×240 图片卡片在读到图片后自动适配，保留位置和引用身份。

选中图片可拖四边或四角保持比例缩放，默认按 20 单位调整，Alt 自由缩放；内容比例由原图决定，四边白边保持一致。缩放支持撤销/重做和保存重开。更换图片保留位置和外框宽度，按新图片比例调整高度。新增图片按实际占位找空位。

音乐卡片采用左侧圆形唱片、右侧名称/真实格式/蓝色进度条和播放控制的横向布局。点击播放时唱片旋转，暂停保持当前相位；系统减少动态效果设置会关闭旋转。支持静音、进度拖动和前后跳转 10 秒，后台仍保存播放位置与上次播放时间。移除重复播放按钮、路径、进度说明和原生打开按钮；音频使用按需读取的本地 Blob，避免沙盒对自定义 app 协议的播放限制。原默认音频卡片迁移为 500×180，自定义尺寸保留。

拖文章进入本地文件夹 Board 后，Command+Z / Ctrl+Z 可把真实文件移回原目录、恢复卡片身份/位置/尺寸及原有关联线；进入其他层级后也可撤销，Shift+Command+Z 支持重做。后续修改的正文不会回滚；同名文件、外部改名/删除或缺失目录会保留现有状态并说明原因，不覆盖文件。会话关闭后移动撤销历史清空，已保存布局继续保留。自由画板之间的图片/PDF/音频等引用移动也可撤销，不自动移动实体附件。

## 0.1.13 更新

选中组件后，右侧出现圆形连接按钮。按住圆按钮拖到另一组件，显示连线预览和目标高亮，松手完成连接。文章、便签、Board、图片、PDF 和音频都可互连；反向重复连接复用已有连线，自身、空白或取消拖动不会创建。工具栏连接按钮提示圆按钮用法，不再进入两次点击模式。

点击手工连线，右侧详情可调整虚实、粗细或删除。实际文章双向链接可选择「在此画板隐藏」，原文链接保留；右上「恢复隐藏文章连线」可恢复，隐藏状态按 Board 保存。

一次完整拖动或拉伸对应一次位置/尺寸撤销。支持 Ctrl+Z / ⌘Z，Ctrl+Shift+Z / ⌘Shift+Z 或 Ctrl+Y 重做；键盘方向键拉伸也可撤销。几何历史按 Board 独立保留在本次画板会话中，不回滚正文、颜色、叠放顺序、链接或音频记录。关闭重开后保留已保存的位置和尺寸，撤销历史重新开始。

Shift 点击增减多选，Shift 拖动画板空白处框选；普通空白拖动仍用于平移。画板聚焦时 Ctrl+A / ⌘A 全选，正在编辑文字时保留原有文字全选。多选后从卡片顶部或文章拖动把手拖动整组，组内相对位置保持；默认按 20px 移动，Alt 可自由移动。

多选面板支持水平/垂直居中、左/右/顶部/底部对齐，并能指定组件之间的间距后横向/纵向等距排列。对齐以当前选中组的边界为基准；等距按画板单位设置边缘空隙，适用不同尺寸的组件。整组移动、对齐或排列都作为一次撤销步骤保存。

点击画板空白处清除组件高亮、选择操作栏、圆形连接按钮和详情面板；平移、缩放和操作浮动工具不会误取消选择。
